# NumPy Field Notes

A beginner's guide to NumPy for civil engineering students who are learning data analysis. Written in simple English.

**By Nacho Moreno**, civil engineering student.

## What's inside

| File | What it is |
|---|---|
| `index.html` | The study guide: arrays, ufuncs, broadcasting, aggregation, indexing, axis. It has interactive demos, a self-check quiz and an English → Spanish vocabulary list. |
| `numpy-practice.ipynb` | 33 exercises with civil engineering data (concrete tests, settlement, column loads, rainfall). The solutions are at the end. |

## How to use it

- **Guide:** open `index.html` in your browser, or visit the GitHub Pages link of this repository.
- **Exercises:** open `numpy-practice.ipynb` in [Google Colab](https://colab.research.google.com/) (File → Upload notebook) or in Jupyter.

The numbers in the examples are realistic, but they are for practice only. They are not real project data.
